## Practicals

The `25200800044_Practical` directory contains twelve practical assignment folders. Each practical includes:

- `Source/` for source code
- `docx` for execution screenshots
- `README.md` for assignment notes

## Skills

The `25200800044_Skill` directory contains twelve skill assignment folders. Each skill folder includes source files, output files, a README, and a Makefile.

## ForgeOS Project

`ForgeOS` contains two semester project modules:

- `Shellforge`: a custom shell programming project
- `NanoKernel`: a minimal kernel and systems programming project

Each module has separate `src`, `include`, and `docs` directories with project-specific build files.
